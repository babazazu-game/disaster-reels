# Витрина Playgama — «Spin the Chaos!» (только локально, НИЧЕГО не загружено)

Файлы для карточки игры в консоли Playgama. Загружает их человек сам.

| Файл | Размер | Что это |
|---|---|---|
| `cover_landscape.jpg` | 1920×1080 | обложка широкая |
| `cover_portrait.jpg` | 1080×1920 | обложка вертикальная |
| `cover_square.jpg` | 800×800 | обложка квадратная |
| `screenshots/1.jpg … 8.jpg` | 1920×1080 | меню, барабан, хаос, середина раунда, лава, победа, персонажи, энциклопедия (английская версия) |
| `video_1920x1080.mp4` | 1920×1080, 30 к/с, ~30 с | геймплей: барабан → хаос → лава → «YOU SURVIVED!», музыка игры |

## Как пересобрать
1. Запустить игру: `npm run dev` (порт 5210).
2. `node tools/store_media.cjs`: кадры раунда (английский, бессмертие, игроком управляет скрипт). Это около 10 минут, **запускать без других браузеров параллельно**, иначе кадры выйдут пустыми.
3. `node tools/store_covers.cjs`: фоны обложек без интерфейса.
4. `python tools/store_make.py`: ролик, скриншоты, обложки (`--covers` пересобирает только обложки).

Сырые кадры `frames/` в git не попадают.

## Перед загрузкой на Playgama
- В `public/playgama-bridge-config.json` стоит заглушка `REPLACE_WITH_PLAYGAMA_PUBLIC_TOKEN`: вписать токен игры из консоли.
- Места рекламы: награда `bonus`, межстраничная `outpost`.
- На модерацию отправляет только человек в консоли.

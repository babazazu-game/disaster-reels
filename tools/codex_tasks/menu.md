Ты пишешь код для детской браузерной игры (Three.js + TypeScript + Vite) «Крути хаос!» / «Spin the Chaos!»: раунд 60 секунд на летающем острове, барабан из трёх лент выдаёт катастрофу («5 огненных котов»), надо выжить. Аудитория — дети, телефон и компьютер, портрет и альбом.

Задача — НОВЫЙ файл `src/game/menu.ts`: главное меню, пауза и экран итога. Всё DOM поверх холста.

ПРАВИТЬ/СОЗДАВАТЬ ТОЛЬКО `src/game/menu.ts`. Другие файлы параллельно правит другой разработчик (встраивать меню в игру будет он). НЕ запускай git. В конце `npx tsc --noEmit -p .` — без ошибок. Комментарии на русском, коротко объясняют ПОЧЕМУ.

Прочитай для стиля и приёмов: `src/game/roundUi.ts` (единица `--u` от короткой стороны экрана, толстая белая обводка, глянцевые плашки, жёлтая кнопка, шрифт Rubik 900, `installTap`), `src/game/reels.ts` (как сделан показ/скрытие через opacity/visibility/inert).

## API (ровно такой — им будет пользоваться src/game.ts)

```ts
export type Difficulty = 'easy' | 'normal' | 'chaos';
export interface ResultInfo {
  win: boolean;
  title: string;        // «ТЫ ВЫЖИЛ!» / «ТЫ ПОГИБ»
  cause?: string;       // причина гибели, «Огненная курица»
  time: number;         // сколько продержался, с
  round: number;        // длина раунда, с (60)
  botsAlive: number; botsTotal: number;
  best: number;         // рекорд по времени на этой сложности, с
  newBest: boolean;     // побил рекорд — праздничная плашка «НОВЫЙ РЕКОРД!»
  difficulty: Difficulty;
}
export class Menu {
  constructor(parent: HTMLElement, L: (ru: string, en: string) => string);
  onPlay?: (d: Difficulty) => void;     // ИГРАТЬ в главном меню
  onRetry?: () => void;                 // ЕЩЁ РАЗ на итоге / ЗАНОВО в паузе
  onMenu?: () => void;                  // МЕНЮ на итоге / в паузе
  onResume?: () => void;                // ПРОДОЛЖИТЬ в паузе (и Esc)
  onPause?: () => void;                 // нажата кнопка паузы в углу (и Esc во время игры)
  onMute?: (muted: boolean) => void;
  onCharacters?: () => void;            // кнопка ПЕРСОНАЖИ (пока раздела нет — см. ниже)
  showMain(d: Difficulty, muted: boolean): void;
  showResult(r: ResultInfo): void;
  showPause(muted: boolean): void;
  hide(): void;                         // спрятать любой экран
  get open(): boolean;                  // открыт ли какой-то экран
  setPauseButton(visible: boolean): void; // маленькая круглая кнопка «пауза» в правом верхнем углу (во время раунда)
}
```

## Экраны

1. **Главное меню.** Фон — полупрозрачная тёмно-синяя вуаль (сзади видна живая арена — игра под меню продолжает рисоваться). Сверху крупный логотип текстом: «КРУТИ / ХАОС!» (en: «SPIN THE / CHAOS!»), белый с тёмной обводкой, второе слово жёлтое, лёгкий наклон и мягкое покачивание. Ниже:
   - **Выбор сложности** — три крупные карточки-плашки в ряд (в узком портрете — тоже в ряд, но компактнее): иконка (SVG прямо в коде: улитка/ромашка для лёгкого, щит или сердце для обычного, молния/взрыв для хаоса), название и одна короткая строка:
     - Лёгкий / Easy — «5 сердечек, всё медленнее» / «5 hearts, slower chaos»
     - Обычный / Normal — «3 сердечка» / «3 hearts»
     - Хаос / Chaos — «2 сердечка, всё быстрее!» / «2 hearts, faster chaos!»
     Выбранная — приподнята, яркая, с толстой белой обводкой и галочкой; остальные приглушены. Цвета: зелёный / синий / красно-оранжевый.
   - **ИГРАТЬ** — самая крупная жёлтая кнопка (как `.rui-btn`, но больше), пульсирует. Enter/пробел = играть.
   - Ряд из двух круглых/квадратных кнопок поменьше: **ПЕРСОНАЖИ** (иконка человечка; раздела пока нет — по нажатию показать над кнопкой на 1,5 с плашку «Скоро!» / «Soon!» и вызвать `onCharacters`) и **звук** (иконка динамика / перечёркнутого динамика, переключает и зовёт `onMute`).
   - Переключателя языка НЕТ и не будет (правило площадки: язык выбирается автоматически до первого кадра).
2. **Итог раунда** (заменит панель в roundUi). Карточка по центру:
   - заголовок `title` (зелёный при победе, красный при гибели), при гибели под ним `cause`;
   - полоска-прогресс «продержался `time` из `round` с» с анимацией заполнения ~0,6 с;
   - строка «Ботов уцелело: X из Y» с маленькими иконками-человечками (уцелевшие цветные, погибшие серые);
   - «Рекорд: N с» (на этой сложности, маленькая плашка с названием сложности); если `newBest` — сверху карточки праздничная наклонная лента «НОВЫЙ РЕКОРД!» / «NEW RECORD!» с выпрыгиванием;
   - кнопки: **ЕЩЁ РАЗ** (главная, жёлтая, крупная) и **МЕНЮ** (вторичная, белая с синей обводкой). Enter = ещё раз.
   - Кнопки доступны сразу, без ожидания.
3. **Пауза.** Карточка «ПАУЗА» / «PAUSED»: ПРОДОЛЖИТЬ (главная), ЗАНОВО, МЕНЮ, кнопка звука. Esc = продолжить.
4. **Кнопка паузы в углу** — круглая ≥44 px, белая обводка, две вертикальные полоски; справа сверху с учётом `env(safe-area-inset-*)`; не должна налезать на таймер по центру сверху и сердечки слева. Esc во время игры (когда экран не открыт и кнопка видна) = `onPause`.

## Требования
- Появление экранов — «выпрыгивание» (scale с лёгким перелётом, ~0,3 с), скрытие — fade + `visibility:hidden` + `inert` + `pointer-events:none`: после `hide()` ничего не перекрывает экран и не ловит касания (под меню — джойстик и кнопка прыжка).
- Всё помещается без прокрутки в портрете 360×640 и в альбоме 640×360, и на десктопе 1920×1080. Кнопки ≥44 px по короткой стороне. Тексты не вылезают (длинные английские тоже) — `clamp`, перенос, уменьшение.
- Клавиши: только когда соответствующий экран открыт; слушатель один на документ; не мешать игровым клавишам, когда экраны закрыты (кроме Esc для паузы).
- Нажатия кнопок — через `click` (installTap из `src/engine/tap.ts` уже делает быстрые тапы на телефоне — подключи как в roundUi).
- CSS — один `<style>`, классы с префиксом `mnu-`, z-index выше `.rui-*` (у них 6–9), например 20.
- Шрифт — `Rubik` (его подключит другой разработчик), запасной `"Arial Black", system-ui, sans-serif`.
- Никаких внешних картинок и библиотек: иконки — инлайн SVG.
- Тексты только через `L(ru, en)`.

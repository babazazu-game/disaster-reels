Ты пишешь код для детской браузерной игры (Three.js + TypeScript + Vite) «Крути хаос!». Заказчик выбрал новый стиль интерфейса — **«конфетный» (вариант 1)**. Образец: `art/ui/v1_candy.jpg` — ОТКРОЙ И РАССМОТРИ картинку (инструмент просмотра изображений). Текущий интерфейс заказчик назвал «паршивым», нужно, чтобы выглядело как образец: дорогая казуальная мобильная игра для детей.

ПРАВИТЬ ТОЛЬКО: `src/game/menu.ts`, `src/game/roundUi.ts`, `src/game/reels.ts` (в reels — только оформление/CSS и разметку рамки; логику вращения, API и анимацию лент НЕ трогать). Другие файлы правит другой разработчик. НЕ запускай git. В конце `npx tsc --noEmit -p .` — без ошибок. Комментарии на русском, коротко объясняют ПОЧЕМУ. API классов `Menu`, `RoundUi`, `Reels` не менять (ими пользуется src/game.ts).

## Стиль (по образцу)
- Шрифт **Nunito 900** (уже подключён в index.html), запасной `"Arial Black", system-ui, sans-serif`. Все надписи — белые или очень светлые с **толстой тёмной обводкой** (`-webkit-text-stroke` + `paint-order:stroke fill`) и тенью-«толщиной» снизу; на жёлтых кнопках можно тёмно-коричневый текст без обводки — как смотрится лучше.
- Кнопки — **пузатые глянцевые «конфеты»**: насыщенный вертикальный градиент, толстая тёмная обводка (тёмно-фиолетовая/тёмно-синяя, ~4–6 px от `--u`), снизу «толщина» более тёмного тона (box-shadow 0 Npx 0), сверху белый полупрозрачный блик-полоса (псевдоэлемент с градиентом, скруглённый), при нажатии кнопка проседает вниз. Сильное скругление (пилюля для ИГРАТЬ).
- Цвета образца: ИГРАТЬ — ярко-розовая/малиновая (#ff3d7f → #e0186a), Лёгкий — зелёная (#5fe04a → #2fae2a), Обычный — жёлто-оранжевая (#ffd23a → #ff9d14), Хаос — фиолетовая (#a35bff → #6a2fe0), круглые кнопки — голубая (#3fc4ff → #1580e8) и фиолетовая. Обводки — тёмно-фиолетовый #2a1250 / тёмно-синий #14204a.
- Карточки сложности как в образце: крупная иконка в карточке, название сверху, выбранная — крупнее, приподнята, с золотистой обводкой/свечением и зелёной галочкой-кружком сверху; невыбранные чуть меньше и темнее. Короткая подпись («5 сердечек…») — мелко внизу карточки, но читаемо; если в узком портрете не помещается — допустимо прятать подпись и показывать её только у выбранной.
- Панели (итог, пауза) — не белые прямоугольники, а «конфетные» панели: светлый градиент (кремово-белый → светло-голубой или светло-сиреневый), толстая тёмная обводка, внутренняя светлая кайма, большое скругление, заголовок — на выпуклой цветной ленте/плашке, выступающей сверху за край панели.
- Вуаль под меню — лёгкая (арену за меню должно быть хорошо видно, как в образце; можно radial-gradient: прозрачно в центре, темнее к краям), а не сплошная синяя.
- Логотип — картинка `assets/ui/logo.webp?v=${__BUILD__}` (будет положена другим разработчиком; соотношение примерно 3:2, прозрачный фон). Если картинка не загрузилась (onerror) — показать текущий текстовый логотип. Лёгкое покачивание/«дыхание» логотипа.
- Иконки — картинки `assets/ui/icons/<name>.webp?v=${__BUILD__}` (прозрачный фон, квадрат), имена: `easy` (пёрышко), `normal` (дорожный конус), `chaos` (торнадо), `people` (группа людей — кнопка ПЕРСОНАЖИ), `sound`, `mute`, `heart`, `clock`. Если иконка не загрузилась — оставить текущий SVG/эмодзи (fallback), чтобы ничего не ломалось.
- ИГРАТЬ — самая крупная, по центру, пульсирует, по бокам маленькие жёлтые «лучики-искры» (как в образце, CSS-псевдоэлементы).
- Кнопка ПЕРСОНАЖИ — круглая/квадратная голубая конфета с иконкой `people` (текст можно убрать, оставить aria-label); звук — фиолетовая конфета с `sound`/`mute`.

## HUD раунда (roundUi.ts) — тот же стиль
- Сердечки — картинки `heart` (fallback — текущий SVG), потерянные — серые и меньше, встряска при потере сохранить.
- Таймер — тёмно-фиолетовая пилюля с толстой обводкой и иконкой `clock`, цифры белые; последние 10 с — красная и пульсирует.
- Крупная надпись волны (`announce`) — Nunito 900, белая/цветная с толстой тёмно-фиолетовой обводкой и тенью, «выпрыгивание» с перелётом.
- Старую панель итога в roundUi не трогать (она больше не используется, итог показывает menu.ts) — но и не удалять API.

## Барабан (reels.ts) — только оформление
Рамка как в образце (врезка внизу справа): фиолетово-розовая глянцевая рамка с золотистой каймой и «лампочками» по краю (маленькие светлые точки, можно мигание), ленты кремовые с внутренней тенью, кнопка СТОП — большая глянцевая красная круглая конфета с белым текстом и тёмной обводкой. Размеры и положение (на телефоне по центру, на компьютере внизу) — как сейчас.

## Требования
- Всё помещается без прокрутки: портрет 360×640, альбом 640×360, десктоп 1920×1080; кнопки ≥44 px; тексты (и английские) не вылезают и не рвутся посреди слова.
- Никаких внешних библиотек и картинок кроме перечисленных `assets/ui/...`.
- Производительность: без тяжёлых `filter: blur` на больших площадях и без `backdrop-filter` (слабые телефоны); анимации — transform/opacity.

Для самопроверки можно временно создать демо-HTML в корне — в конце удалить.
